# MedAI Android App

Это базовый Android-скелет для дальнейшей разработки мобильного клиента MedAI.

## Что включено

- проект на Kotlin;
- корневые настройки Gradle;
- минимальный `MainActivity` и layout;
- безопасный медицинский интерфейс с предупреждением о прототипе;
- подготовка к дальнейшему развитию функциональности ECG и рабочего процесса.

## Запуск

1. Открыть папку `android/MedAIApp` в Android Studio.
2. Дождаться синхронизации Gradle.
3. Выбрать устройство или эмулятор.
4. Нажать Run.

## Ограничения

- это каркас, а не готовая клиническая система;
- код предназначен для дальнейшей реализации экранов, безопасности и интеграции с API.
