# MedAI

MedAI — исследовательский прототип помощника для предварительной структуризации фотографии ЭКГ.

> Текущая версия не ставит диагноз, не исключает заболевания и не заменяет врача.

## Структура

- `web/` — существующий веб-прототип и новый каркас ECG Assistant.
- `web/ecg/` — изолированный интерфейс помощника по фотографии ЭКГ.
- `docs/` — границы MVP, безопасность и контракт отчёта.

## Запуск каркаса

```bash
cd web/ecg
python3 -m http.server 8000
```

Открыть `http://localhost:8000`.

На этом этапе реализованы только структура интерфейса, выбор изображения, предпросмотр и безопасный пустой шаблон отчёта. Медицинский анализ ещё не реализован намеренно.
