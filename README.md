# MedAI

MedAI — исследовательский прототип системы поддержки первичной оценки ЭКГ и медицинской организации задач.

> Приложение не ставит диагноз и не заменяет врача. На текущем этапе это безопасный каркас с ограниченной функциональностью и понятными границами.

## Что было исправлено

- устранена конфликтующая структура: в репозитории существовали два разных интерфейса с дублирующей логикой;
- приведены документы к единому описанию проекта;
- восстановлена корректная веб-структура и работа с привычным запуском;
- подготовлен Android-скелет как основа для мобильной версии.

## Архитектура

- `web/` — основной веб-дашборд MedAI и рабочая панель задач;
- `web/ecg/` — интерфейс для загрузки фотографии ЭКГ и предварительного отчёта;
- `docs/` — ограничения MVP, безопасность и контракт данных;
- `android/MedAIApp/` — полноценный каркас Android-приложения на Kotlin.

## Быстрый запуск веб-версии

```bash
cd /workspaces/Medai/web
python3 -m http.server 8000
```

После этого открыть:

- http://localhost:8000/
- http://localhost:8000/ecg/index.html

## Быстрый запуск Android-структуры

1. Открыть папку `android/MedAIApp` в Android Studio.
2. Подождать синхронизацию Gradle.
3. Запустить проект на эмуляторе или устройстве.

## Статус

- веб-интерфейс готов для локального запуска;
- ECG-прототип безопасно ограничен по функциям и не выполняет медицинскую интерпретацию;
- Android-скелет готов к дальнейшей разработке экранов, анализа и интеграции API.
