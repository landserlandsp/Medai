# 🌐 MedAI Web Application

Веб-версия MedAI - это современное приложение для управления медицинскими задачами, написанное на чистом HTML, CSS и JavaScript.

## ✨ Возможности

### ✅ Полнофункциональность
- 📝 Добавление и удаление задач
- ✓ Отметить задачу как завершённую
- 🔍 Фильтрация (Все, Активные, Завершённые)
- 📊 Статистика выполнения задач
- 💾 Автосохранение в браузер (localStorage)
- 🎨 Адаптивный дизайн для всех устройств
- 🌓 Поддержка темного режима
- ⌨️ Горячие клавиши

### 🔒 Безопасность
- XSS защита через escapeHtml
- Проверка входных данных
- Валидация длины текста (макс. 200 символов)

### ♿ Доступность
- Семантический HTML
- ARIA метки
- Поддержка клавиатурной навигации
- Контрастные цвета

## 🚀 Установка и запуск

### Требования
- Современный браузер (Chrome, Firefox, Safari, Edge)
- Нет никаких зависимостей!

### Локальный запуск

#### Вариант 1: Через Python
```bash
cd web
python3 -m http.server 8000
# Откройте http://localhost:8000
```

#### Вариант 2: Через Node.js
```bash
cd web
npm install -g http-server
http-server
# Откройте http://localhost:8080
```

#### Вариант 3: Через Live Server (VS Code)
1. Установите расширение "Live Server"
2. Откройте `index.html`
3. Кликните "Go Live" в правом нижнем углу

#### Вариант 4: Просто откройте файл
```bash
# MacOS
open index.html

# Linux
xdg-open index.html

# Windows
start index.html
```

## 📚 Архитектура

### Класс `TodoApp`

Основной класс приложения с методами:

```javascript
// Основные методы
app.addTodo()           // Добавить новую задачу
app.toggleTodo(id)      // Отметить как выполненную
app.deleteTodo(id)      // Удалить задачу
app.clearCompleted()    // Очистить выполненные
app.deleteAll()         // Удалить все задачи
app.setFilter(filter)   // Установить фильтр
app.exportData()        // Экспортировать в JSON
app.importData(file)    // Импортировать из JSON
```

### Структура данных TODO

```javascript
{
  id: 1234567890,              // Уникальный ID (timestamp)
  text: "Обследовать пациента", // Текст задачи
  completed: false,            // Статус выполнения
  createdAt: "2026-08-22...",  // Дата создания
  priority: "normal"           // Приоритет
}
```

### Хранилище данных

Все данные сохраняются в `localStorage` браузера:
- Ключ: `medai_todos`
- Формат: JSON массив
- Максимальный размер: ~5-10 MB (в зависимости от браузера)

## 🐛 Известные ограничения

| Проблема | Причина | Решение |
|----------|---------|---------|
| Данные теряются при очистке кэша | localStorage не синхронизируется | Экспортируйте данные регулярно |
| Максимум ~10 MB данных | Ограничение браузера | Используйте экспорт/импорт |
| Без синхронизации между устройствами | PWA ограничение | Используйте облачный сервис |

## 🧪 Тестирование

### Ручное тестирование
```javascript
// Откройте DevTools (F12)
// Консоль:

// Добавить 5 тестовых задач
for(let i = 1; i <= 5; i++) {
  app.todos.push({
    id: Date.now() + i,
    text: `Тестовая задача ${i}`,
    completed: i % 2 === 0,
    createdAt: new Date().toISOString(),
    priority: 'normal'
  })
}
app.render()

// Очистить все данные
localStorage.clear()
location.reload()
```
