# MedAI Web

Веб-часть проекта состоит из двух блоков:

1. `web/` — рабочий дашборд MedAI и список задач для передвижения по медицинскому процессу;
2. `web/ecg/` — исследовательский интерфейс для загрузки ЭКГ и формирования безопасного предварительного отчёта.

## Запуск

```bash
cd /workspaces/Medai/web
python3 -m http.server 8000
```

Открыть:

- http://localhost:8000/
- http://localhost:8000/ecg/index.html

## Принципы

- всё хранится локально;
- изображения не отправляются на сервер;
- нет диагностических выводов без проверки медицинским специалистом;
- UI оставляет строгие оговорки и безопасные статусы.

## Текущий статус

Базовый интерфейс запускается локально, а ECG-модуль остаётся прототипом с безопасным ограничением на интерпретацию.
