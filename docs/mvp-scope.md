# Scope MVP: ECG Assistant

## Цель

Создать небольшой помощник, который принимает фотографию ЭКГ, оценивает техническую пригодность изображения и формирует структурированный предварительный отчёт для обязательной проверки врачом.

## Входит в первый MVP

1. Выбор изображения локально.
2. Предпросмотр без отправки на сервер.
3. Проверка типа, размера и базового качества файла.
4. Явное состояние `не готово к интерпретации`.
5. Структура отчёта с измерениями и уровнем уверенности.
6. Очистка изображения из текущей сессии.

## Не входит в первый MVP

- постановка диагноза;
- исключение инфаркта или другого заболевания;
- рекомендации по лечению;
- автоматическая экстренная сортировка пациентов;
- хранение персональных данных;
- отправка изображений во внешние сервисы;
- обучение модели на непроверенных данных.

## Критерий готовности каркаса

Пользователь понимает, что происходит с изображением, видит ограничения системы и не получает медицинского вывода до появления проверенного алгоритма.
